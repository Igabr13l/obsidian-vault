# 70 - Cociente de Reaccion y Le Chatelier

> [!INFO] Fuente
> Basado en [[CBC/QUIMICA/TRANSCRIPCIONES/70. Química. Cociente de reacción y principio de Le Chatelier|la transcripcion del video 70]] y apuntes de Quimica del CBC.

---

## Idea central

El cociente de reaccion `Q` permite comparar el estado actual del sistema con el equilibrio, y el principio de Le Chatelier ayuda a predecir hacia donde se desplazara.

---

## Comparacion entre `Q` y `K`

- si `Q = K`, el sistema esta en equilibrio
- si `Q < K`, el sistema tiende a formar mas productos
- si `Q > K`, el sistema tiende a formar mas reactivos

---

## Principio de Le Chatelier

- el sistema responde para oponerse parcialmente a la perturbacion
- sirve para predecir desplazamientos, no para cambiar `K` salvo cambio de temperatura
