# CBC Obsidian Vault

Apuntes y materiales de estudio para las materias del CBC (Carrera de Básico Común).

## Materias

- **BIOLOGÍA** - Biología Celular
- **IPC** - Introducción al Pensamiento Científico
- **QUÍMICA** - Química General

## Contenido

Cada materia incluye:
- Sesiones teoricas
- Examenes (parciales y recuperatorios)
- Materiales opcionals
- Transcripciones de clases

## Cómo usar

Este vault está diseñado para usar con [Obsidian](https://obsidian.md).
