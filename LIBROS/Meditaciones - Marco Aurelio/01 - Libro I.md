# Libro I — Deudas de Gratitud

El unico libro autobiografico. Marco Aurelio no habla de si mismo, sino de **lo que aprendio de cada persona** en su vida. Es un ejercicio de gratitud y reconocimiento.

## Lecciones clave

| Persona | Leccion |
|---------|---------|
| **Abuelo Verus** | Modales y dominio de la ira |
| **Padre** | Humildad, no presumir de rango, no hacer las cosas a medias |
| **Madre** | Piedad, generosidad, no hacer el mal ni siquiera pensarlo |
| **Bisabuelo** | No frecuentar escuelas publicas, buenos maestros en casa |
| **Rustico** | No interesarse por retorica superficial, leer con profundidad |
| **Apollonio** | Libertad, determinacion, confiar en la razon |
| **Sexto** | Benevolencia, vivir conforme a la naturaleza |
| **Alejandro el Gramatico** | No corregir a otros con rudeza, no senalar errores gratuitamente |
| **Fronton** | Que la tiranía trae desconfianza y falsedad |
| **Severo** | Justicia, igualdad, la idea de un gobierno de leyes iguales |
| **Maximo** | Dominio de si mismo, serenidad ante todo |
| **Los dioses** | Haber tenido buenos abuelos, padres, hermana, maestros, amigos |

> [!QUOTE] Frase clave
> "De Severo: el amor a la justicia, el ideal de un gobierno de igualdad de derechos y de igual libertad de expresion, y el concepto de una monarquia que honra ante todo la libertad de los gobernados."
