## Descripcion

Walkthrough de los laboratorios de PortSwigger Web Security Academy usando BurpSuite. Cubre desde vulnerabilidades comunes hasta tecnicas avanzadas de hacking web.

## Temas cubiertos

- XSS (Reflejado, Almacenado, DOM)
- SQL Injection
- CSRF
- SSRF
- IDOR / Broken Access Control
- SSTI
- XXE
- Request Smuggling
- WebSocket attacks
