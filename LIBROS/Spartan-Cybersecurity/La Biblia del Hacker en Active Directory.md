# La Biblia del Hacker en Active Directory

> [!INFO] Fuente
> E-book gratuito de Spartan-Cybersecurity. Disponible en [books.spartan-cybersec.com/cpad](https://books.spartan-cybersec.com/cpad).

## Descripcion

Guia exhaustiva de pentesting en Active Directory. Muestra herramientas y comandos para identificar vulnerabilidades en entornos AD. Diseñado para quienes buscan roles de red team.

## Temas cubiertos

- Enumeracion de AD (BloodHound, LDAP)
- Kerberoasting
- AS-REP Roasting
- Pass-the-Hash / Pass-the-Ticket
- DCSync
- Golden / Silver Ticket
- ACL abuse
- AD CS (Certificate Services)
- Kerberos delegation
