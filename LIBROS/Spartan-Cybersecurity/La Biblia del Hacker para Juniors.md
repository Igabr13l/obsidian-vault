## Descripcion

Libro generalista que cubre conceptos fundamentales de ciberseguridad ofensiva. Diseñado para llevar a un principiante a nivel junior solido. Enfoque amplio sin profundizar extremadamente en cada tema.

## Temas cubiertos

- Fundamentos de redes y protocolos
- Linux para hacking
- Reconocimiento y OSINT
- Vulnerabilidades web clasicas
- Introduccion a Active Directory
- Metodologia de pentesting
- Herramientas del oficio (Burp, nmap, metasploit)
